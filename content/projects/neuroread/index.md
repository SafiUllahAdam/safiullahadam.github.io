**NeuroRead** — my flagship NLP project — is a **Retrieval-Augmented Generation (RAG)** application for intelligent querying of PDF and DOCX research documents.

<!--more-->

I designed and orchestrated multiple LLM providers — **OpenAI API, Gemini, Hugging Face, Groq, and LangChain** — for context-aware reasoning, multimodal knowledge retrieval, and adaptive text generation. I also built an end-to-end validation pipeline for data extraction, consistency checking, and output verification.

The project earned me the **Top Performer Award** at the Pakistan Engineering Council Generative AI Application Developer Program (2025).
