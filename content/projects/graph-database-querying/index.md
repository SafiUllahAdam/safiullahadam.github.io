This academic project compared two graph paradigms by analysing an ICIJ property graph in **Neo4j/Cypher** and querying the **DBpedia RDF knowledge graph** with **SPARQL**.

<!--more-->

The Neo4j part used **Cypher queries** to inspect offshore-entity structure, source-level edge patterns, officer-to-entity connections, country grouping, temporal filters, and graph quality constraints such as struck-off status consistency and registration/incorporation date validation.

The DBpedia part explored **semantic web querying**, retrieving artists born in Paris, relationships between artists and cities, artworks in smaller locations, and optional population attributes using RDF triples, IRIs, and ontology-aware SPARQL patterns.

**Core concepts**

- **Property graph analysis** — node/relationship modelling, aggregation, traversal, and temporal filtering in Neo4j.
- **Graph data validation** — constraint checks for struck-off entities, registration dates, and relationship lifetimes.
- **Knowledge graph querying** — RDF triples, SPARQL SELECT/OPTIONAL patterns, and linked open data exploration.
- **Graph technology comparison** — property graph vs RDF knowledge graph for real-world and public datasets.

The project sharpened skills in graph analytics, query languages, data governance, semantic web modelling, and large connected-data reasoning.
